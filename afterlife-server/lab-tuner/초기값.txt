# lab-tuner 기본값(default) — 2026-08-18 KST

실통화 튜닝으로 확정해 **코드 기본값으로 승격**한 세팅입니다(knobs.py).
랩을 재기동해도 이 값으로 시작하므로, 되돌리려면 랩만 재기동하면 됩니다.

## 이 세팅이 만드는 동작

- 입   : 오디오 기반 · 벌림 0.7 · 배율 1.3 (잠금 3종 해제)
- 눈   : 고정 + 2초 간격 깜빡임
- 표정 : animation_region=all · 세기 0.1 · 배율 0.25 (억제)
- 머리 : 흔들림 폭 1.2 · 감속 1.5 (느긋) · 말 안 할 때 정지

🔑 animation_region 은 **all** 이어야 머리가 움직입니다. FLP 가 머리 회전을
   `if animation_region in ["all", "pose"]` 로 감싸서, exp 로 두면 머리 흔들림
   값을 아무리 올려도 무시됩니다(2026-08-18 실측).

## 조절 손잡이 (자주 쓰는 것)

| 하고 싶은 것 | 노브 | 반영 |
|---|---|---|
| 입을 더 벌리기 | 벌림 배율 ↑ (벌림은 1.0 이 상한) | 즉시 |
| 머리를 더/덜 흔들기 | 흔들림 폭 | 즉시 |
| 흔들림 속도 | 감속 (클수록 느긋) | 즉시 |
| 깜빡임 빈도 | 깜빡임 간격 | 즉시 |
| 표정 크기 | 표정 세기 · 움직임 배율 | 렌더서버 재기동 |

## 주의

- 표정 세기 0.1 은 권장 하한(0.5)보다 낮습니다 — 의도적으로 억제한 값입니다.
- 깜빡임 간격은 '눈 뜬 채 고정=true' 일 때만 쓰입니다. 끄면 JoyVASA 네이티브
  눈 움직임이 되고 간격은 3.2초로 고정됩니다(코드 하드코딩).
- 브라우저에 저장된 옛 값이 서버를 덮어쓸 수 있습니다. 값이 자꾸 되돌아가면
  화면의 '저장값 지우기' 를 누르세요.
